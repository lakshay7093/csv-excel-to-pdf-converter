# CSV & Excel to PDF Converter 📄

A simple Streamlit app that converts CSV or Excel files into clean, styled PDFs.

## Features
- Upload CSV or Excel files
- Preview data before export
- Convert tables to styled PDF
- Clean UI using Streamlit
