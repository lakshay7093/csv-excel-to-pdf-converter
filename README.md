# CSV & Excel to PDF Converter 📄

A simple and efficient **Streamlit-based web application** that converts **CSV and Excel files into clean, well-formatted PDF documents**.  
The tool allows users to upload datasets, preview the data, and export it into a professionally styled PDF with just one click.

This project demonstrates **data processing, file handling, and PDF generation using Python.**

---

## 🚀 Features

- Upload **CSV or Excel files**
- **Preview dataset** before conversion
- Convert tables into **clean, styled PDFs**
- **Simple and user-friendly UI** using Streamlit
- Supports **multiple rows and structured tables**
- Fast and lightweight processing

---

## 🛠 Tech Stack

- **Python**
- **Streamlit** – UI and web interface
- **Pandas** – Data processing
- **ReportLab / PDF Library** – PDF generation
